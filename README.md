# 데이터를 읽는 감각 — 물류 자동화 현장의 센서

물류 자동화 현장의 기술자(비전공자 포함)를 위한 온라인 기술서. 전 4부 15장.

지은이 강승태 · 작성일 2026-08-10

## 읽는 법

| 형태 | 파일 | 설명 |
|---|---|---|
| 웹 | `index.html` | 표지와 차례. 여기서 시작한다 |
| 단일 파일 | `Understanding-the-Data-Flow-of-Logistics-Automation-Processes-Based-on-Sensors.html` | 전체를 파일 하나로 묶은 판. 외부 참조 없음 |

## 구조

```
content/          ← 사람이 고치는 곳은 여기뿐이다
  preface.html      머리말
  1-1.html … 4-3.html   본문 15장

assets/
  style.css         공통 스타일
  index.css         표지 전용

build.py          content/ → 개별 페이지 (목차·번호 자동 생성)
make_back.py      찾아보기 5종 생성 (용어·그림·표·약어·참고문헌)
bundle.py         전체를 단일 HTML 파일로 묶기
refdata.py        발행처 표기 · 자료 종류 · 약어 목록
```

## 고치는 순서

`content/` 안의 파일만 고치고, 아래를 차례로 실행한다. 목차·그림 번호·표 번호·색인·내부 링크는 전부 자동으로 다시 만들어진다.

```bash
python3 build.py        # 개별 페이지
python3 make_back.py    # 찾아보기 5종
python3 bundle.py       # 단일 파일
```

표준 라이브러리만 쓴다. 설치할 것이 없다.

`make_back.py`는 실행할 때마다 수집 건수를 출력하고, 하나라도 0이면 멈춘다.

```
수집: 용어 132 · 참고 230 · 그림 66 · 표 62
```

## 만들 때 지킨 것

- 색은 6가지만 쓴다. 강조색(골드)은 **주의**에만 쓴다
- 강조 상자는 개념 · 현장 · 주의 세 종류만 쓴다
- 표의 수치에는 출처를 붙인다. 없으면 「저자 판단」이라고 적는다
- 링크는 실제로 열어 내용을 확인한 것만 쓴다
